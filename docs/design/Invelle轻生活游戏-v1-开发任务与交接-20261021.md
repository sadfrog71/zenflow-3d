- **当前目标**：在现有 Invelle 中接入 Blender 园境，形成个人小世界、养鱼与布置、许愿树交流、天气变化，以及原有聊天／阅读／抄写／记录。保留四入口和既有账号。
- **最新用户意图**：整理可直接接续的开发任务，尽量减少返工；先考虑 iPad 的视觉体验，身边暂无实体 iPad，询问电脑调试路径，并补齐需求说明、第一视角操作、数据接口及本机存储机制。本任务建议并采用「iPad 横屏优先 → 浏览器构图 → iPad 原生模拟器 → iPhone 适配 → 真机验收」顺序。iPhone 仍在首版范围内。
- **已有成果**：两份总体设计及四份实施说明；20 项功能需求、14 个视点、16 项绑定、12 条用户路径；36 项业务验收、10 项操作检查、16 项存储检查；一个可交互的独立浏览器样板。样板有演示身份和本机存档，不能当正式账号或后端。
- **优先处理**：G00 基线 → G01 共用契约 → G02 小资源包及 WebView 加载 → G03 iPad 导航容器。先证明真实运行路径，再扩功能，避免在假浏览器环境里完成全部页面后重做。
- **最重要的边界**：共用场景资产，每个账号有独立状态；朋友也不能读取对方私人世界。所有分享明确确认；社区、媒体与身份由服务端授权。

## 3. 先冻结的共用契约

G01 的交付必须可供客户端、服务端、后台使用。先完善已有两份设计及 `src/contracts/zenflow/`，只补缺少的契约文件，不再复制一套全量规格。以下是技术设计默认值；影响用户可见规则的变更须明确说明。

| 编号 | 开始实现前必须明确的内容 | 会造成返工的错误 |
| --- | --- | --- |
| C01 身份与归属 | tenant、APP_USER、owner 来自受信会话；业务 ID 不是授权；异步任务与缓存带原始身份代次 | 依靠前端切换对象或传 ownerId 隔离 |
| C02 类型及版本 | API 使用既有命名；逻辑 ID 跨 JS 边界按字符串处理并核对旧契约；服务端时间统一 UTC，显示再本地化；expectedVersion／stateVersion 明确 | 大整数精度丢失、设备时间排序、不同模块各写版本规则 |
| C03 园境状态 | fish、placements、environment；每类变更有限字段 PATCH，未出现字段保持不变；游客导入明确选择，不带入私人正文 | 全量最后写入覆盖别端或旧客户端删掉天气字段 |
| C04 资源清单 | sceneVersion、schemaVersion、包 hash、解码器兼容、稳定 view／anchor／archetype ID；原始对象名只在映射层 | 模型改名导致存档和接口一起重写 |
| C05 天气 | 六个 presetId，灯光独立开关；设备静音／减少动态不随账号强制同步；预览、取消、保存、未知值回退 | 为天气复制整园、自动改写未知预设、无限组合预设 |
| C06 投稿与审核 | POST／WISH／REPLY／FOLLOWUP；根签、回复对象、版本快照、匿名、关闭回应、撤回传播 | 旧客户端混入新条目，未审核回应泄漏，修改附件绕过复审 |
| C07 关系与来信 | 双方用户对唯一；请求、接受、拒绝、取消、移除、屏蔽状态；双方同时请求要有确定结果；发信时事务内复验 | UI 显示朋友就永久放行，解除屏蔽自动恢复好友，重复请求建多条关系 |
| C08 媒体用途 | PRIVATE_NOTE／PUBLIC_SUBMISSION／FRIEND_LETTER 等用途集中枚举；一个上传只绑定预期用途与内容版本；播放按父对象重验 | 复制 mediaId 就公开私人音频，永久公开 URL 绕过撤回 |
| C09 事件与幂等 | 同身份同键同内容返回原结果，同键异内容冲突；内容写入与 outbox 同事务，recipient+eventKey 去重；worker 按事件类型认领 | 上传完成等于发信成功，超时重试产生第二封信，假通知 |
| C10 删除与生命周期 | 本人隐藏、作者撤回、拉黑、账号删除、举报证据保留分别定义；关系移除后旧来信的读取规则须统一到权限矩阵 | 把本人删除当双方物理删除，举报后开放整箱，撤回后 CDN 仍能永久访问 |
| C11 能力与错误 | 用 bootstrap 既有 capabilities 扩展统一名字，明确与设计中 `sceneAvailable` 等含义的映射；401／403／404／409／413／422／429／503 按既有错误格式 | 页面自建开关、禁用 AI 导致无法记事、失败显示成功 |
| C12 输入与返回 | 原生页控制正文、录音、手写；WebView 只发白名单动作；当前地点、返回来源、草稿身份随会话保存 | 旋转丢草稿、编辑时拖镜头、临时纸被普通自动保存持久化 |

C10 的建议默认：移除朋友后禁止新来信，历史已送达信件仍仅双方按原归属读取；屏蔽按当前设计阻断相关读取，解除屏蔽不恢复朋友；撤回内容继续不可读。应在 G01 将这一建议写进统一契约并覆盖测试，不让前后端自行猜测。举报证据保留期限不由开发者随意定死，公开运行前确认并配置。

推荐连续开发顺序：先 G00–G03 获得可运行的 iPad 空间（只用虚构数据，不提前持久化真实草稿）；再 G04、G05 建立身份与本机存储，继续 G06–G11 完成一条真实的许愿树交流路径；然后 G12–G15 接入完整私人生活；最后 G16–G19。不要求一次做完全部页面才验证端到端。没有原声配置时可以先实现文字贯通，但不能将原声从首版范围删除。

### G00：建立可恢复基线

1. 核对根仓库、当前 HEAD、脏文件及本地资料是否齐全；记录源文件 hash，不替用户提交或搬移工作。
2. 核对固定 p3-v039 .blend／GLB 与绑定表哈希；检查 p3-v042 只作为候选，不默认升级。禁止把运行时适配写回建模主文件。
3. 检查 `prototype/`、三个工程依赖、现有 build 脚本及本机模拟器；不存在时先说明具体缺项，不改依赖版本凑通过。
4. 对计划修改的旧功能做最小基线核对，失败分清既有问题与新增回归。输出当前可运行路径及缺配置项的名字，不输出值。

完成证据：基线、缺口清单、选定模拟器和资源版本。缺少实体 iPad 标为设备验收未验证，不视为所有开发阻塞。

### G01：冻结接口与数据变更

在既有 `zenflow-mobile/src/contracts/zenflow/`、`src/core/zenflow/` 与服务端业务层约定 C01–C12；明确 JSON 样例、可空字段、限制、状态转移、分页和错误格式。新增源码放现有三工程，不能另建认证或媒体平台。

数据库按园境、媒体、社区扩展、关系／信件等依赖拆新增迁移；当前本地最高 P11，写入前重查，不能直接约定编号永远是 P12。唯一键包含适当租户和主体范围，列出高频查询索引与老数据默认值；新增列先兼容旧读写，再开放 capability。

列出新增路径到 Controller、边界过滤器、安全配置、产品 gateway 的对应表；后台路径和 APP 路径分别验证。API 不允许客户端指定任意 owner、存储键或公网对象地址。

将[接口对应](Invelle轻生活游戏-v1-数据与接口对应-20261021.md)中的新增回执、初建园境、媒体整文件上传及旧接口兼容具体化；本机 schema 与服务端 SQL 分开，L 检查不当作数据库已迁移。

完成证据：可编译契约／固定样例、迁移草稿、状态转移表、权限与负向用例；尚无环境时不执行 SQL。

### G02：先证明模型能在实际容器运行

复用 `garden.tsx`、`garden-files.ts`、`scripts/zenflow/build-garden.cjs` 和现有 Three.js。实现廊下、鱼塘、许愿树的可重复导出／加载路径；先保留近区与必要远景，再按实测裁剪、拆包和共享纹理，不直接把母模型当发行包。

关键试验是 **WKWebView 的 GLB、纹理、解码器加载**。现有小图片 Data URL 方案不得无评估扩成全模型 Base64；先用最小含纹理 GLB 在模拟器检验二进制文件路径、资源访问范围及离线行为，再扩大至三个区域。沿现有构建管线新增必要源模块，生成物仍由脚本产生，不直接手改 `*-source.json`。

不复用样板的本机 Python 服务作为 App 运行依赖，不扩大 WKWebView 到任意来源权限。不依赖 `zenflow-space` 的可变预览 URL 作为正式资源入口；正式清单要固定 hash 和相容版本。

记录首帧、包大小、解码、draw calls、三角形、纹理、内存趋势；浏览器／模拟器只作为开发对照。先定测量方法和同一场景，再定预算；没有最低实体机时不宣称满足移动硬件预算。样板合批曾减少调用但恶化观测帧间隔，默认不照搬。

完成证据：真实 App 中三处可加载与往返；断网已缓存可用、失败可重试、资源升级不破坏旧版本。G02 缺真机时仍可完成开发通路验证，性能验收保留未验证。

### G03：iPad 容器与导航

先以 11 英寸 iPad 横屏核对构图，再覆盖 13 英寸、mini、竖屏／窄窗口。改 `app.json` 等已有脏配置时保留其他 WIP，核验生成后的设备族、方向、安全区和 bundle；不只在桌面改变 CSS 宽度。

实现 GardenShell、SceneHost／Bridge、NavigationState；14 个视点按稳定 ID 落点，点击前往、短淡变或减少动态立即切换，不用直线飞越穿墙。`GLTFLoader` 世界变换是坐标依据，不二次转换 Blender 轴。

优先接 N00／N01／N03。没有正式热点的喂鱼、摆放、信盒、朋友、笔记本等先在资源映射中补 runtime 代理和原生替代按钮，明确其为应用适配；需要改视觉实体时另提建模补件，不把任意网格冒充真实物件。完整缺件清单来自绑定 JSON。

实现输入／手写／摆放模式互斥、键盘避让、返回来源、旋转恢复、前后台暂停、WebGL context lost 和内存压力后的恢复；账号变化先遮住私人界面并取消请求，旧回调不可回填。浏览器仅作为同一运行模块的开发壳，不复制第二套业务状态。

### G04：账号与能力基础

复用 `session.ts`、`oauth.ts`、`external-login.ts`、服务端 `identity/`。邮箱密码留在已有认证页；access token 内存、refresh token 安全存储。登录取消返回原园境动作，恢复草稿后仍需本人再次确认投稿／发信。

补 Apple 授权码／撤销与账号删除完整处理、Apple 用户增加已验证邮箱密码，以及冲突／解绑最后登录方式规则；提供方稳定身份是主键，不按邮箱自动合并，隐藏邮箱也能稳定回到原用户。相关 Apple 协议实现时按官方文档核对，密钥独立配置，不写客户端。

拆 bootstrap capabilities，明确 AI 不可用时园景、笔记与已开通社交是否可用；保留 Google／Facebook 既有代码及生产构建约束，不能因首屏只放 Apple／邮箱而弄坏老用户登录。

源码与替身测试可先做；真实邮件、Apple 凭证、用户销号与授权撤销在获准测试身份和环境中验证，不用生产用户试错。

### G05：私人园境与共用本机存储

先按[本机存储机制](Invelle轻生活游戏-v1-本地存储与同步机制-20261021.md)完成原生 SQLCipher 小样、SecureStore 钥匙、媒体加密与崩溃恢复。新增 expo-sqlite 的理由是草稿／队列原子事务；先核对 SDK 57 兼容，锁定依赖，不升级整套 Expo。Mac 浏览器使用同接口的虚构数据适配器，iPad 模拟器验证实际存储；没有真实草稿保护前，录音／投稿页只接测试数据。

实现每账号唯一园境，鱼实例、摆件及 `{presetId,lampEnabled}` 保存；坐标／锚点／数量／可选鱼型和参数均在服务端白名单校验。临时水纹和每帧状态只在本地。

PATCH 只提交操作范围与 expectedVersion。冲突保留本机编辑，显示重新加载／有针对性的明确重试；未知鱼型或摆件保留原数据并收纳，升级不静默删除。游客试玩不产生云端账号，导入时不覆盖已有园境。

本机草稿、下载、离线队列按 tenant／subject／owner 及身份代次隔离。切账号同时停止旧队列，不能改用新账号令牌继续旧请求；A→B→A 必须验证原账号、重新确认适用的操作并绑定新派发代次，不能沿旧会话自动重放。补齐冷启动离线锁定、同账号草稿恢复、版本冲突、回执未知及删除竞争。L01–L16 随媒体／笔记功能分段完成，到 G17 汇总，不要求 G05 单独验证尚未实现的远端业务。

### G06：媒体门面与生命周期

在产品业务层新增用途受限的上传／状态／播放／删除门面，复用 FileTemplate 能力；不要开放企业 `SysFile` 旁路，也不把音频伪装成聊天附件。

上传声明、流式接收、complete 校验、绑定内容是不同阶段。校验大小、真实类型、可解码时长和所有者，限制并发与重试；文件名不作存储路径，不公开原 storageKey。媒体绑定必须与父内容版本对应，不能把已有私人资产换 purpose 升为公开。

播放支持所需 Range，同时每次复核父对象可见性、关系／屏蔽／撤回和账号状态。公开与私人缓存策略分开；短期下载授权不能变成永久共享权限。账号切换清理私人播放缓存，日志不打印正文／原声／令牌。

未完成上传、孤立草稿、撤回派生文件和账号删除有可恢复清理任务；复用 zf_outbox 的事件隔离、租约、重试和终态记录，避免误消费现有笔记删除事件。证据保留与普通删除路径分开。

### G07：原生原声体验

优先使用已有 expo-audio，实现录制 → 停止 → 试听／重录 → 明确范围 → 保存／提交。长度与容量暂沿设计候选 60 秒／5 MiB，由统一配置下发或一致校验，不在多个页面分别硬编码。

一个 AudioCoordinator 处理原生识别、录音、来信播放、环境声和雨声；同时只用一个录音会话。电话打断、切后台、耳机断开、拒绝权限均有可恢复结果，不自动发出未确认内容。

聊天已有识别后自动发送规则保持在聊天入口；社区、手记、来信不共享该开关。转写失败保留原声草稿，公开审核仍针对完整音频与文字版本；私人转写不自动启动。权限文案与实际保存行为一致，配置插件和打包后 Info.plist 一并核对。

### G08：公共愿签服务

扩展既有 community 包及 P06 所建表，用新迁移加入 entryKind／根签／回复对象／匿名／语言／回应开关；旧 category 与旧客户端未传 kind 时继续只得到 POST。

公开根签、回应、后续都先审核。根签撤回／下架后子条目与媒体访问同步失效；不是只把列表上的一行隐藏。作者关闭新回应时，在事务中与并发创建复验。

列表按批准时间及稳定 ID 游标；每页重新校验权限与屏蔽，不能凭旧 cursor 穿透。有限批次，主动查看更多；空页如实，新增消息不替换正在读的条目。不加入点赞、粉丝、热度和无限滚动。

### G09：关系、来信和通知

朋友请求接受／拒绝／取消／移除、相向请求及屏蔽有唯一状态转移；关系变更带版本，并发同意或重复操作幂等。公开名片只投影 publicId、主动昵称、头像，不能回退到邮箱。

发信事务同时核验双方当前关系、屏蔽状态、账号状态和媒体归属；上传完成不等于送达。历史信件的删除／撤回／移除读取按 C10 统一，匿名签不能暴露身份供加好友。

真实内容事件与 outbox 同事务，站内 inbox 按接收者去重，重试不重复提示。通知引用目标，目标失效后不返回敏感摘要；不新增推送、在线状态或全园多人 WebSocket。

### G10：后台审核与治理

扩展 `Community.vue`、`src/api/zenflow/client.ts` 及既有后台入口；显示根签上下文、提交版本、文字、图片、完整原声与转写。批准前核对当前版本，旧审核动作不能批准已修改或撤回内容。

拒绝、下架、关闭传播与用户端状态一致；不可凭转写文本代替听审原声。普通运营只见主动投稿和明确举报的选定证据，不见私人笔记或全信箱。处理权限、审计、对象版本和禁止缓存私人内容都进入验收。

资源目录只配置已审核的场景版本／预设，不建设在线 Blender 编辑器。配置缺失明确显示能力不可用，不做假后台成功状态。

### G11：树下完整路径

接入真实 G08／G09 服务；WishComposer、WishTreePanel、FriendsPanel、MailboxPanel 复用媒体组件及统一状态。iPad 场景与面板并置；关闭面板回树下原视点，私人记录留在小屋。

用两个明确的测试账号完成 J01–J04：文字与原声、待审、批准、回应、后续、朋友、来信、举报、撤回；公共挂签动画不能早于批准。模拟数据仅用于隔离的 UI 开发，不和真实服务混用，不将演示身份入口打进正式包。

### G12：养鱼与局部布置

鱼型模板映射已有五种外观，用户鱼的 instanceId 独立；按初始 3／最多 5 的可配置候选实现，实际规则变更只改统一配置。喂鱼／拨水即时反馈，本人命名和布置明确保存。

摆放受批准区域限制，提供非拖动操作、旋转、撤销和取消。离开、旋转、背景恢复及版本冲突时不丢编辑；不加入饥饿、死亡、货币、稀有度、刷鱼或社交解锁。

### G13：天气与时段

将 day／dusk／night／rain／dawn／sunset 映射到独立 EnvironmentController；先校准天空、照明和湿材质，再补雨丝／涟漪／屋檐遮雨及授权音源。历史状态清单版本不一致，需针对当前固定模型生成一致资源描述。

预览／取消／保存不重建整园，取消还原材质与灯光基线；连续切换不累加灯光或泄漏纹理。夜间不能暗到找不到路或读不了文字。关灯及减少动态独立于 preset；低画质降效果，不更改本人选择。

归属、跨端同步、离线和未知值沿 G05；天气不会伤鱼、改变别人的世界或社交权限。首版不读取位置、不调用真实天气 API、不做自动情绪天气，也不扩大到未验证的雪／雷暴或全部组合。

### G14：阅读、私人记事和聊天复用

直接接 `book-shelf.tsx`、现有笔记与聊天 API，保持书籍版本／章节／语言／滚动位置，补引用锚点和私人媒体附件。书架正在有其他工作，改前先读 diff；不改书籍正文排版来适配三维纸面。

私人手记与愿签投稿是不同动作，私人原声不进公开审核或 AI。带笔记聊聊沿已有当轮选择及授权；鱼塘、浏览、朋友来信不自动作为 AI 上下文。保留取消、SSE 恢复、引用权限及记录删除链路。

### G15：手写及其他已确认互动

手写先做可编辑笔迹源／预览图／版本恢复的小样，再接 PencilKit 或现有适配；手机与无笔设备仍可指触或键盘输入，不能只存截图称支持继续编辑。

临时纸只保留易失状态，不接普通草稿持久化；持久记事本使用不同入口。呼吸只由用户主动开始，停止后可继续坐着，不产生未完成训练。园景明信片只截场景画布，不包含私人面板／通知；先私人保存，发给朋友再核对接收者。

### G16：iPhone 与全尺寸适配

沿同一契约和逻辑视点，将内容页切成手机全屏，保留返回栈、草稿、核心功能和真实语音。按实际宽度而非单纯平台判断决定侧栏／全屏；iPad 分屏同样走窄窗口布局。

核对 safe area、动态字号、VoiceOver、长中文／英文、键盘和系统手势。手机专用相机变体挂在同一 viewpointId 下，不复制存档。不能用删掉社交／阅读／天气来换性能。

### G17：集成、失败恢复与旧版本回归

以开发设计 A01–A36 为唯一矩阵，逐条关联测试、截图／录屏、构建与环境。先跑受影响单测，再做服务联调及 UI；权限必须直接构造 A／B／管理员越权请求，不能只看按钮是否隐藏。

重点注入：超时后重试、上传中切账号、A→B→A、审核时撤回、发信时移除关系、离线冲突、资源损坏、GL 上下文丢失、后台录音中断、版本升级与回退。测试数据可识别并与真实私人数据隔离。

旧客户端 POST、既有聊天／记录／书架和现有提供方登录必须回归。未接真实提供方／数据库／设备时写 PARTIAL 或 NOT_VERIFIED，不能用 H2 或桌面截图覆盖结论。

### G18／G19：准备与执行分开

G18 输出按名列出的迁移、网关变更、对象存储配置项、资源清单、实际包校验办法、备份／恢复与回退步骤。读取项目明确指定的部署文档，不寻找通用清单扩大范围。当前任务不连接生产库、不执行迁移或发布。

获得对应操作授权后，G19 才核验真实目标、备份、演练、配置和版本并执行。生产关闭新增能力或切回旧兼容资源可以作为回退，但不能删除新增用户数据；数据库／对象存储绑定应共同可恢复。最终再补真实 iPad 及 iPhone 的性能、触控、声音、Apple 登录与可用性，发布状态独立报告。
