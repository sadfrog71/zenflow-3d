# Invelle 轻生活游戏 v1：第一视角操作规范

> 2026-10-22 导航修订：首次进入全园俯视图，再进入所选空间全景，最后显式进入第一视角。返回逐级退出。以下旧路径中的 N00 起点应在此三级导航之后理解；导航状态须同时保留 nodeId 与 level。以[导航层级修订](Invelle轻生活游戏-v1-导航层级修订-20261022.md)为准。

日期：2026-10-21。状态：交互实现约束，未以真机验收。对应[需求说明书](Invelle轻生活游戏-v1-需求说明书-20261021.md) FR01–FR03、FR06–FR19；任务 G02、G03、G07、G11–G16。地点及相机的唯一目录继续使用[产品设计第 6 节](iPad轻生活游戏-v1-产品与空间设计-20261021.md#6-第一视角导航和动作路径)和[绑定 JSON](ipad-v1-evidence/spatial-bindings-v1.json)，不复制或另编一套 N 编号。

## 1. 视角和导航约定

首次进入全园俯视图；选择廊下后先显示空间全景，显式进入第一视角后到达 N00 廊下坐姿。玩家不显示第三人称角色；坐下与起身是切换已验证视点和操作姿态，不增加角色养成。相机采用模型导出的世界矩阵，应用层按可用画幅适配；不直接套 Blender 原始坐标。

点击明确的地点标记或地点列表先进入目标空间全景，再由明确按钮进入目标第一视角。默认短淡变，减少动态时直接到达；不会把两相机直线插值当成步行路线。无自由移动摇杆、WASD、陀螺仪瞄准、自动绕园或鼠标锁定。用户停止输入后镜头停止，不加入默认摇晃、呼吸起伏或无限惯性。

地点切换顺序固定为：检查目标与资源 → 结束／保存当前可恢复操作 → 暂停旧热点 → 淡出 → 更新视点与热点 → 淡入 → 宣告到达。资源失败留在原地点并提示；不得落到空场景。切换中只处理返回／取消，其他目的地点击忽略且不排队；完成后可重新点击。

每个 viewpoint 配置 `defaultPose`、允许的 yaw／pitch 范围、画幅变体、near／far 与合法热点集合。具体角度、视野及过渡时长由 G02 样板确定并写入资源清单，逐点检查墙体、水面、地平线和大字号面板遮挡；不要给全园套同一个未经验证的角度。首版固定焦距，场景双指捏合不改变镜头；正文／手写画布内的缩放由该组件单独接管。

## 2. 操作模式与输入归属

状态由原生 GardenShell 持有，WebView 只执行当前被许可的场景动作。同一时刻只允许一个主模式。

| 模式 | 允许的输入 | 场景响应 | 离开方式 |
| --- | --- | --- | --- |
| LOADING／TRANSITION | 取消或返回、允许的重试 | 禁止点击热点及拖镜头 | 完成或回原稳定视点 |
| IDLE_LOOK | 点地点／物件，拖空白环顾 | 仅当前视点已启用热点 | 打开内容或进入物件模式 |
| POND_INTERACTION | 点喂食、在水面拨动、点鱼选择 | 相机锁定；只改变本地鱼行为 | “完成”回原朝向 |
| PLACEMENT | 选物件、允许平面内拖动、显式旋转／收纳 | 锁镜头；合法／非法位置明确标识 | 保存或取消后退出 |
| CONTENT_PANEL | 阅读、列表、播放按钮、返回 | 停止场景手势，背景降低渲染 | 关闭面板回原视点 |
| EDITING／DRAWING | 原生文字、笔迹、组件内滚动缩放 | 触摸不穿透；不触发热点 | 持久草稿完成写盘后关闭；临时纸另行处理 |
| RECORDING | 停止、取消；显示时长／限额 | 麦克风独占，暂停其他人声与环境声 | 停止进入试听，取消清理本次录音 |
| SUSPENDED | 无内容交互 | 暂停渲染／音频，遮盖私人画面 | 身份与资源复核后恢复安全状态 |

PLAYBACK 是内容面板内的音频子状态，不另开可穿透场景的模式。开始新的人声播放先停止旧播放；进入录音前停止语音识别和播放器。退出播放页停止播放，首版不保留后台来信播放。

## 3. 手势判定和无障碍替代

| 操作 | iPad／iPhone | Mac 浏览器调试 | 明确边界 |
| --- | --- | --- | --- |
| 点选 | 单指按下并在同一目标抬起 | 左键点击 | 滑动后不得再产生点击 |
| 环顾 | 空白区域单指拖动 | 左键拖空白 | 仅 IDLE_LOOK；内容区域完全阻断 |
| 喂食／拨水 | 先点“与鱼玩一会儿”，再点或拖水面 | 同样先进入模式 | 不把水面任意点按当作导航 |
| 布置 | 专用编辑模式中拖动，按钮旋转 | 拖动及旋转按钮 | 只在清单允许区域；非法位置不能保存 |
| 写字 | 指触或 Pencil；键盘方式始终可达 | 鼠标画笔／键盘仅验证功能 | 鼠标效果不证明压感、掌拒或笔触舒适度 |
| 返回 | 原生返回／关闭；适用页面系统返回手势 | 可聚焦返回按钮、Escape | Escape 不自动丢草稿／公开／发送 |
| 视角复位 | 明确“回正视角”按钮 | 同名按钮 | 不以双击、长按或隐藏手势承载必需功能 |

初始调参建议：按下至抬起移动不超过 8 个逻辑单位且持续不超过 350 ms 才作为点击候选；超过移动阈值即进入拖动态。数值为调试起点，不是舒适度结论。原生 pt、RN 逻辑单位与 WebView CSS px 的换算在桥接层校准，不能用渲染像素或 devicePixelRatio 直接乘阈值。长按未绑定业务；多指加入、pointercancel、失焦或旋转均取消本次点击判定，不触发抬手误操作。

热点可见、在允许视域内且未被遮挡时才可命中。命中体与装饰网格分离；屏幕投影后的有效触控区至少 44×44 pt，邻近热点重叠时显示可读候选或优先明确按钮，不随机选择。墙后热点不可因射线命中扩大区域而被点到。提供名称、焦点及原生地点／物件列表，VoiceOver 用户不必操作三维画布。[Apple 游戏控件指南](https://developer.apple.com/design/human-interface-guidelines/game-controls)

键盘 Tab／Enter 可完成所有原生核心按钮；焦点进入面板标题或首个合理控件，关闭后返回触发按钮。悬停提示只辅助鼠标，不作为触摸端发现功能的前提。按钮尺寸、边缘安全距离、文字可读性按实际截图与设备检查。

## 4. 各地点如何进入与返回

| 场景 | 打开动作 | 操作结束后的确定结果 |
| --- | --- | --- |
| N00 廊下 | 地点按钮／四入口 | 关闭设置回廊下，天气仅确认后成为本人偏好 |
| N01 鱼塘 | “看鱼”／互动／布置分别进入 | 互动结束回原镜头；布置取消还原进入前快照 |
| N02 坐垫 | 点坐垫落座，主动开始呼吸 | 停止后仍可坐着；点起身回进入处，不显示失败 |
| N03 许愿树 | 取签／读签／朋友／信盒 | 合上内容回树下原朝向；草稿存本机；投稿待审不挂公共签 |
| N04、N05 书房 | 选书进入原生阅读，摘句再开笔记 | 关闭笔记回同版本同章定位；合书回 N05 |
| N06、N07 抄写 | 选择左右手视点后打开纸页 | 保存可编辑源与预览；退出回纸案；未存云端不假称同步 |
| N08 私人小屋 | 记事本或临时纸明确分开 | 记事草稿可恢复；临时纸离开销毁且不进入自动保存 |
| N09 对话小屋 | 选择原会话或新会话 | 退出面板不隐式删除会话；返回来源笔记或原坐席 |
| N10 钟庭 | 点可交互钟 | 有静音视觉反馈，无音频权限也能退出 |
| N11、N13 通路／前门 | 前往相邻地点或打开地点列表 | 不要求逐段步行才能访问功能 |
| N12 观景 | 明确“拍园景” | 先隐藏全部私人面板，再捕获场景；预览页选择私人保存／寄送 |

`CAM_POND_LIFE`／`CAM_KOI_CLOSE` 是构图参考，不自动成为玩家落点。缺少信盒／笔记本实体时可以先用标明用途的原生按钮开发，验收单记录缺件，不绑定到无关纸张或模型节点冒充完成。

## 5. 返回、旋转和中断

返回优先级：系统输入法收起 → 结束当前局部编辑／停止录音 → 关闭子页 → 关闭主面板 → 原地点。具体页面可提供独立“完成”，避免每次关闭都需要多次返回；不得以系统返回直接触发发送。录音未结束先停止并进入试听草稿，只有明确“删除”才丢弃本次录音。

普通文字与手写草稿通过本机存储服务持久化，保存成功后可直接退出，无需反复弹确认；写盘失败时保留编辑器并说明未保存，可重试或明确放弃。未确认的摆放／天气是预览，返回提示保存或取消。临时纸入口已说明不保存，关闭即销毁；后台时清空其敏感画布，不将它放入快照或最近任务缩略图。

导航恢复对象包括 `nodeId`、视点变体、允许范围内 yaw／pitch、模式、来源栈、内容 ID／版本、滚动锚点、本人 `draftId`。不保存令牌、私人正文或媒体 URL 到 WebView/localStorage。记录只在当前账号解锁空间可读取；回复对象已失效时保留本人草稿并说明不可继续回复。

旋转／分屏：取消当前手势，重新计算可用尺寸及相机画幅，保留所在地点、面板、草稿、列表位置；不重新提交请求、不重新开始录音。键盘出现时提交按钮仍可见且正文可滚动；窄窗口切全屏内容，大窗口恢复侧栏。分辨率／质量变化不影响功能权限。

后台／电话／锁屏：停止录音并尽力封装草稿，停止播放，暂停渲染，关闭数据库句柄与内存钥匙，应用切换画面遮盖私人内容。回到前台不自动续录或播放；同进程同账号且身份未失效可重新解锁本机，网络权限需另验。进程被杀后的冷启动按存储文档处理，不靠旧 UI 状态继续发送。

WebView 被系统回收：重新握手并创建新的 sceneInstanceId，加载同版本已验证资源，原生层恢复可渲染园境快照；此前未处理的桥接请求作废。若账号改变，回公共默认视点，不能先闪现旧用户鱼名或草稿。

## 6. 桥接消息约束

建议消息示例仅表示请求前往地点，不授权读写业务：

```json
{
  "protocolVersion": 1,
  "requestId": "req-example-001",
  "sceneInstanceId": "scene-example-01",
  "identityGeneration": 8,
  "type": "hotspot.activate",
  "payload": { "anchorId": "wish.take", "viewpointId": "N03" }
}
```

白名单校验协议版本、实例、身份代次、动作与当前模式、锚点是否属于当前视点。原生重新决定是否需要登录、是否允许打开或保存。未知字段／类型拒绝并记录安全错误码，过期消息丢弃；建议单条上限 16 KiB，超过不执行。图片、音频、笔迹文件走原生文件服务，不经 postMessage 大串 Base64 传输。

状态类消息附单调 `sceneStateSeq`；重复或倒退不覆盖新状态。业务动作 `requestId` 去重并回 `ack`／`reject`；没有 ack 时最多同 ID 重试，实例变化即取消。`navigate.to` 的到达回执带原请求 ID；等待超时只解除加载并回安全状态，不凭延迟回调二次切地点。超时阈值由 G02 实测配置，不能阻塞返回。

原生传给场景的园境快照只含渲染所需鱼／摆件／环境及逻辑 ID；鱼名虽可渲染，仍按私人内存处理。正文、信件、邮箱、账号 ID、令牌和存储钥匙不进入场景。

## 7. 操作验收清单

| ID | 检查 | 必须观察到的结果 |
| --- | --- | --- |
| I01 | 缺资源、切地点中取消、连续点击、场景回收 | 原稳定视点可恢复，无穿墙／空白落点／迟到跳转 |
| I02 | 点热点后拖动、长按、多指、pointercancel | 不误点、不同时转镜头与执行业务 |
| I03 | 墙后／相邻／边缘热点及地点列表 | 遮挡正确、名称明确、列表同等可达 |
| I04 | 拨水、拖摆件、写字时拖动 | 只有当前模式响应；非法位置不能保存 |
| I05 | 减少动态、视角复位、夜间、窄窗口 | 无强制镜头运动，地点和操作始终可辨认 |
| I06 | 阅读→笔记→聊天→返回及登录取消 | 原章节／地点恢复，选入授权不被扩大 |
| I07 | 麦克风拒绝、电话／后台、切账号、重录 | 不自动恢复录音／发送；草稿隔离且原文件按规则清理 |
| I08 | 临时纸退出／后台／崩溃重开 | 无持久正文或自动恢复入口 |
| I09 | 私人页上点击园景拍照 | 成片只含场景，无私人正文、UI、姓名或收件人信息 |
| I10 | 大字号、VoiceOver、键盘、旋转、iPad 分屏 | 核心按钮可达，焦点与草稿恢复，无键盘遮挡提交 |

浏览器可验证事件与布局；原生模拟器补 WKWebView／输入与生命周期；实机补触摸、Pencil、音频及晕动舒适度。证据分别记录，不相互替代。
