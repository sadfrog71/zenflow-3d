# Invelle 轻生活游戏 v1：需求说明书

> 2026-10-22 导航修订：首次进入全园俯视图，再进入所选空间全景，最后显式进入第一视角。返回逐级退出。以下旧路径中的 N00 起点应在此三级导航之后理解；导航状态须同时保留 nodeId 与 level。以[导航层级修订](Invelle轻生活游戏-v1-导航层级修订-20261022.md)为准。

## 1. 目标、范围与阅读关系

用户进入自己的安静园境，可以看鱼、布置、选择天气、阅读、写字、记事或聊天；到许愿树主动分享，与陌生人交流，也可在双方同意后持续通信。不以任务、打卡、排名或经济循环推动停留。

[产品与空间设计](iPad轻生活游戏-v1-产品与空间设计-20261021.md)定义区域、模型、J01–J12 路径与参考依据；本说明将这些决定转为可检查的需求。[开发任务书](Invelle轻生活游戏-v1-开发任务与交接-20261021.md)安排 G00–G19；[前后台设计](iPad轻生活游戏-v1-前后台开发设计-20261021.md)保留 A01–A36。配套的[操作规范](Invelle轻生活游戏-v1-第一视角操作规范-20261021.md)、[数据接口对应](Invelle轻生活游戏-v1-数据与接口对应-20261021.md)、[本机存储机制](Invelle轻生活游戏-v1-本地存储与同步机制-20261021.md)约束具体实现，不再建立另一套产品范围。

已确认：个人独立世界、许愿树交流、原声、朋友来信、Apple／邮箱、双端、天气及电脑开发路径。设计默认值：点选地点淡变、六个环境预设、有限批次浏览、原声暂按 60 秒／5 MiB 限制、加密存储选型、冷启动离线策略。后者是可评审的实施建议，不冒充已由用户逐条确认的规则；调整时同步四份配套文档。

首版不包含自由行走操纵杆、实时多人同屏、开放参观他人园境、养殖交易、货币商城、会员支付、排行榜、定位天气、自动昼夜、系统推送及私人资料自动进入公共知识。

## 2. 使用者与权限

| 角色／状态 | 可使用 | 不可使用 |
| --- | --- | --- |
| 游客 | 已下载园景、鱼塘短互动、设备偏好、独立游客布置预览 | 私人云端数据、朋友、投稿、来信；不缓存其他账号资料 |
| 在线已认证 APP_USER | 本人园境、本人记录、符合权限的公共树、朋友请求与来信 | 他人私人世界、未授权记录、被撤回或屏蔽内容 |
| 本次已验证身份后断网 | 本人已解锁本机草稿、已缓存园景、离线改动 | 将本机状态冒充云端成功；取得新的服务端授权 |
| 无网冷启动／已退出 | 游客公共园景；本人存档保持锁定 | 仅凭旧 token 或上次用户名解锁私人数据 |
| 审核人员 ADMIN_USER | 主动投稿快照、被明确提交的举报证据、必要配置状态 | 普通浏览私人记录、录音、信箱和园境 |

好友只增加指定来信权限，不获得园境、笔记、聊天或文件访问权。Apple 隐藏邮箱与普通邮箱相同不触发合并；身份以服务端主体为准。

## 4. 业务状态与用户可见结果

| 对象 | 必须区分的状态 | 禁止混用 |
| --- | --- | --- |
| 草稿 | 编辑中／保存本机中／已存本机／本机保存失败 | “已存本机”不能标成“云端已保存” |
| 园境保存 | 本机待同步／同步中／云端已同步／版本冲突 | 预览不变更云端，未知环境临时回退不改原值 |
| 投稿 | 本机草稿／待审核／已公开／未通过／已撤回／已下架 | 上传完成不等于审核通过；本机挂签预览不等于公开 |
| 来信 | 本机草稿／发送中／结果确认中／已寄出／发送失败／已撤回 | “已寄出”仅表示服务端收件箱落库，不代表推送送达或阅读 |
| 媒体 | 本机草稿／上传中／校验处理／可绑定／已绑定／不可访问／清理中 | 可绑定不等于拥有公开权限；转写完成不等于审核通过 |
| 私人记录 | 本机草稿／云端版本／另存的冲突副本／删除待处理 | 删除失败不能显示已物理清除所有副本 |

首次投稿前显示所选文字／图片／原声、匿名状态及公开范围；寄信显示指定收件人；私人保存说明是否仅本机。确认后形成不可变提交快照，修改内容产生新草稿。默认不会将旧录音附到下一次操作。

电脑浏览器验证构图、手势逻辑和状态；iPad 原生模拟器验证 WKWebView、文件桥接、原生键盘、方向及生命周期。实体 iPad 不在手边不会阻止这些开发；触感、Pencil、GPU 内存、声音舒适度、发热与电池仍保留独立真机门槛。

## 6. 完成条件与变更约束

需求完成须同时具备可运行功能、对应契约、异常路径、权限证据及所声明层次的验收。一个样板通过不能把同名 FR 标为完成。G17 汇总 A01–A36、I01–I10 和 L01–L16，分别标 PASS／PARTIAL／BLOCKED／FAIL，未执行项写 NOT_VERIFIED。

开发可以采用本文明确的默认值继续可逆实现；公开运行前仍需定稿目标年龄范围、审核人员及响应时效、举报证据保留期限、原声限制、音源许可和最低设备。缺真实提供方配置时交付失败态与替身证据，不借用其他项目账号，不伪造真实登录／发送。

每次改变存储保留、自动同步、好友访问、公开范围或账号合并规则，先更新对应 FR 和契约再实现。新增功能不得藏在“顺手完善”中；非本专题未提交修改继续保留。
