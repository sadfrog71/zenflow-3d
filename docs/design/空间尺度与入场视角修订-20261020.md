# 空间尺度、入场视角与明亮风格修订

日期：2026-10-20。承接总纲 v1.2 与效果图评审。

当前 v8 局部修订及读经入口已并入[Blender 制作总纲](禅意空间-设计总纲-v1.2-Blender制作版-20261020.md)，实施从总纲读取。本文保留评审过程；早期比较方案不再与最新正文并列执行。

用户最新修订：俯视世界需要更宏大、容纳未来场景；补齐布景与大房间；明确入场第一视角；现有效果太古朴，应考虑更明亮的日式禅院或唐风。

后续明确反馈：用户接受「素雅唐风」，否决 v3 俯视图，要求总图至少与室内布景一致，并澄清其问题是「显得廉价，不够高级」。因此素雅唐风作为主方向；明亮通透作为光照与材料要求，不再把两套建筑风格并列为待选方案。开间数和面积比例仍是待验证提案。

最新图稿与修订见 [v8 第一视角图册](style-studies-20261020/v8-first-person/README.md)。用户明确保留左侧瀑布、水系、双桥与高台；水中小岛只放一个圆形坐垫，取消台座和靠背，这是室外石坐具规则的局部例外。功能分配沿用 v7：左上许愿树、右上日出云海观景、主院东侧独立对话小屋。v5 中削平水园的简化稿与 v6 左上观景台方案均已被后续要求覆盖。

本文记录的后续明确要求覆盖初稿中的冲突内容，现已统一到制作总纲；原有隐私、无任务压力和直接到读经室等边界继续有效。

## 1. 核心判断

俯视图需要呈现「一个能继续生长的地方」，入口需要呈现「一个已经可以坐下的位置」。世界可以大，眼前不必同时出现所有功能。

前几版的问题不只是镜头近：大部分建筑都是同级小房间，院内装饰细碎，外部土地不足；放大缩放只会得到更远的小院。室内则把自然材质等同于严重做旧，使灰墙、木梁和席面共同指向古宅的陈旧感。

修订分三层：扩大山水园境；拉开厅堂、房间与落座处的尺度差；用浅木、暖白墙与自然天光恢复明亮和舒展。

## 2. 俯视图应该看清什么

### 世界尺度

水系延伸到核心院落之外，地势有高低，林地和远山形成前中后景。留白来自水面、空庭、台地与疏林，不依靠大量雾遮住场景。

扩展位置必须有可用面积、相对平整的地形和接入支路。它们现在就是可成立的草坡、石坪和林间空地，不摆施工围挡、不写「敬请期待」、不造没有功能的新殿堂。

### 建筑尺度

- 读书室提案升级为较大的藏书阅读厅，长书架、开放厅心与临窗坐席共同构成空间，不是把一间小屋里的家具同比放大。
- 读经室提案增加开间和进深，以柱列、纸屏、低案形成多个小尺度位置。大厅不等于公开集体活动，不出现其他用户或强制共修。
- 侧室继续小而私密，形成明显体量差异。
- 廊、门口、水庭与石庭担当过渡，不能每走一段就遇到另一个功能房门。

此前约 10.8×7.2 米的读经室仅为旧灰模起点，本轮不再将其视为不可调整的上限。新增开间数和建筑尺寸待同一灰模比较后确定。

### 功能布景

| 场景 | 必须在模型中存在的物件 | 全景应能判断的关系 |
| --- | --- | --- |
| 廊下与庭院 | 米碟、扫帚、水缸与瓢、石坐具、求助木牌 | 活动靠边，不堵住路径，仍有大面积空庭 |
| 读书厅 | 书架、阅读桌、坐席、小炉与铁瓶 | 是能展开的阅读空间，不是摆着书柜的小客厅 |
| 读经厅 | 低案、席垫、旧纸、砚笔、灯、纸屏、入口净手钵 | 直接可达，有纵深，落座后视域仍能收拢 |
| 侧室 | 靠坐位置、临时纸、浅水槽 | 私密，独立，无需穿过才能到别处 |
| 水庭 | 岸石、鱼、浮叶、投石处 | 水面可观察，岸边有停留位置 |
| 水中冥想台 | 低石坪、石座、通岸石径 | 位于下桥左端小岛，不替换山坡高台 |
| 右上观景台 | 石座、上台路径、北向与侧向观看位 | 检查云海、日出和落日的方位与遮挡 |
| 石庭／廊钟 | 钟、磨痕、石钵或投石水面、少量枯枝 | 可独处，也有直接离开的通路 |
| 左上许愿树 | 空白签、少量木签、风铃、带顶取签盒 | 专做许愿留言，中央大树不重复挂签 |
| 独立对话小屋 | 有靠背的室内坐席、边几、侧窗、短廊 | 与原侧室分开，公共路径不直视室内谈话位置 |

总图无法清楚显示两个字、墨的干湿或钟面磨痕。这些应由局部布景详图和 Blender 物件清单核验，不能要求一张俯视图承担所有验收。

## 3. 两种俯视图的用途

制作总图可以局部剖开屋顶，显示厅堂体量、功能分区、通路和未来扩展地形。它服务设计与建模，不作为玩家必须操作的地图。

世界展示图则应保留完整屋顶，让宽檐、灰瓦与园境关系成立。需要时从同一模型另出，不将剖开的房间视为世界真实状态。

当前 v7 已采用完整屋顶展示图；下一阶段需从同一 Blender 模型输出剖视和坐姿图，核对屋顶、柱间、内部布景与空间高度。

## 4. 进入休息空间的第一视角

这里的「进入」指 Invelle 休息空间，不改动现有聊天、创作、记录等入口。

默认位置为庭院临水侧廊的一处坐席。画面已经稳定，不从山顶飞下来，不从大门开始行走，不先展示地图和房间选项。

镜头初始按坐姿约 1.0–1.15 米校验，宽度以既看见檐柱包围、又不产生广角拉伸为准。第一帧不是抄写特写，也不是空旷大厅正中；周围有依靠，面前有开口。

| 视域 | 第一眼呈现 | 作用 |
| --- | --- | --- |
| 近处 | 一根偏侧廊柱、木地板边缘、几级石阶；杯和米碟择少量出现 | 交代已经坐下、身边有可碰的小事 |
| 中景 | 大片平静水面或院地、一只偶尔经过的鸟、少量树影 | 即使不操作也有可看的世界 |
| 远处 | 灰瓦或宽檐、暖白墙、树与天空之间的空隙 | 暗示世界更大，不一次展示全部目的地 |
| 侧方 | 转向后能看见的廊路和读经室入口 | 探索是可选动作，不是开场决定 |

不要把扫帚、钟、树、书架、纸、呼吸物件全部堆在第一帧。物件齐全是模型要求，不等于第一眼全部可见。

无输入时保持静止镜头，水光或枝影细微变化。触碰可产生局部结果；横向展开廊景可发现其他入口。进入任何房间都不以完成前一个房间为条件。

## 5. 风格选择记录：当前采用素雅唐风

以下表格保留最初比较过程，不代表仍需二选一：

| 维度 | 偏日式禅院 | 偏素雅唐风 |
| --- | --- | --- |
| 优势 | 通透、简净、纸窗软光、坐姿与庭园关系自然 | 宽檐、柱列、开间与屋顶体量更容易形成大气感 |
| 风险 | 容易变成民宿样板间、碎石和盆景堆砌 | 容易变成宫殿／寺院复原、过度对称或过暗的大木构 |
| 本项目取用 | 明亮材质、内外通透、低密度与细腻日光 | 大厅与长廊的结构比例、空间纵深和宽檐 |
| 本项目避免 | 过度陈列、无处不在的装饰灯笼、刻意完美 | 金饰、红墙、佛像主轴、纪念性台阶与仪式关卡 |

当前方向：素雅唐风统一建筑比例、圆柱、宽檐和梁架。日式对照稿只作为明亮采光与材料感的参考，不再另设一套日式建筑；不把两套代表性装饰叠加在同一栋楼上。

室外与廊下白天以暖白墙、浅木、灰瓦、柔和绿和天空反光为主；夜晚保留暗部层次。抄经室的最新参考方向另为「偏暗、成排桌案、暖色灯光」，不强行套用全室明亮的要求。日夜不是两个美术项目，最终应由同一模型、同一材质在不同光照下产生。

「缺陷」缩小为杯沿使用痕迹、席边一处补线、纸张的不齐，不再由整面脏墙、黑木与破席共同表达。明亮也不等于强曝晒：廊下依旧有阴影和遮蔽，纸面不能发白刺眼。

## 6. 技能选择是否改变

主技能仍用 environment-artist，辅助 set-dressing。此次修订进一步说明为何不能直接套候选技能的恐怖光照、默认站姿和废弃物件叙事。材质与灯光配方服从明亮、低刺激、可辨层次的目标。

概念图仅用于风格及空间意图确认；真正的尺寸、完整屋顶、第一视角和功能布景，需要同一 Blender 灰模与资产清单验证。

## 7. v4：修复总图与内部布景的对应关系

### 图稿依据

v3 唐风入口图提供已接受的风格方向；v2 日间读经室提供低案、席垫、侧窗、纸门和相邻空置案席关系，旧暗色和过重做旧不再沿用。v3 总图仅保留各功能的相对位置和大小关系，不能继续作为可信的室内总装图。

| 区域 | 必须一致的关系 | 旧总图需要修正的地方 |
| --- | --- | --- |
| 临水入口 | 木廊在水庭东岸，坐姿望向西侧水面；近处圆柱、宽石阶、杯与石座；室外软垫已被后续要求替换 | 廊与水面之间不能再插入白墙或大片植物，入口视线必须在总图中成立 |
| 读经厅 | 保留低案、席地坐垫、背后暖白墙、纸门与相邻静处；后续参照用户明确的偏暗、成排桌案、暖光方向调整 | 不采用教室式高桌椅或无结构依附的屏风；低案可依柱列形成秩序。门窗朝向须在同一模型中固定，地下参考尚未匹配到具体照片 |
| 读书厅 | 书架靠墙，阅读位和小炉靠边，中间留通路；材质、梁柱和低坐体系统一 | 不以食堂长桌替代阅读布景，不让书架阻断直接进入读经厅的路径 |
| 私密侧室 | 小体量、独立入口、软靠与低案、沿墙浅水槽 | 不扩大成第三间公共大厅 |
| 小石庭与树下 | 钟、石钵与树的区域保持可达；相对主庭与主厅是次要场景 | 不把小物件夸张放大成总图中心；保留用户后续指定的既有高台，不再额外复制圆形台座 |

### 高级感的具体修订

旧稿的问题包括满地碎石与小植物、重复圆台地、过度均匀的细节密度，以及剖开屋顶后几乎消失的厅堂结构。修订通过建筑尺度、材质差别与景观取舍处理，不用加金饰、家具或提高饱和度代替。

1. 保留大部分真实屋顶体积，只剖开两座厅堂朝镜头的一段屋面；屋脊、后坡、宽檐、梁架和柱列仍可读。
2. 庭院、水面、墙面形成完整的大面，树石成组；大幅减少均匀散布的小花、小灌木和碎石。
3. 木、瓦、石、灰泥各自有不同粗糙度与细节尺度；远山和远树降低对比，廊下保留反射光与阴影层次。
4. 这是 v4 阶段的简化建议。后续用户已要求保留既有台地并赋予用途，因此以第 8 节为准；剩余扩展空间可继续使用自然缓坡和林地。

### 核验边界

图像编辑可以校正可见的功能位置、材料和布景类别，但不是几何一致性的证明。概念稿需逐项注明可见结果与剩余偏差；后续精确一致的总图、室内和入口镜头应从同一个 Blender 场景输出，不继续分别想象三套空间。

### 围墙逐段判断

| 位置 | 处理 | 理由 |
| --- | --- | --- |
| 前方入口外墙与入口门 | 保留 | 提供一次明确的进入边界 |
| 两座大殿柱廊前平行的内层矮墙 | 移除 | 已有外墙，再围一层会遮挡柱廊并切碎前庭 |
| 左侧临水廊下及其短回墙 | 移除，保留屋顶与柱列 | 打开庭院、坐席与水面的联系 |
| 后方水园与路径之间的长斜墙 | 移除 | 以地形、岸石和植物即可区分，不需阻断视线 |
| 钟庭后方背景墙 | 保留 | 给钟庭提供背景与安静边界 |
| 私密侧室外侧短墙 | 局部保留 | 仅在需要遮挡的位置使用，不另套封闭小院 |
| 厅堂本身的门窗、围护墙与梁柱 | 保留 | 属于房屋，不是多余的景观围墙 |
| 高台石砌边缘、台阶与岸石 | 保留 | 属于挡土和高差过渡，不与围墙一并删除 |

### 石材坐具的后续建模要求

坐面细磨、边角钝化、使用轻微排水坡；石材侧面保留矿物纹理，使其看起来就是石座，不画成白色软垫。此要求继续适用于高台和廊下，水中小岛改按第 10 节执行。具体尺寸、排水、坐姿舒适度与连续通路属于建模和体验核验项，本轮图片不能证明这些已经完成。

## 9. v7：许愿树与心理咨询式对话小屋

用户已确认：左上平台专做许愿树，观景功能移到右上；树上留言可以被其他用户看见；另设计一间小房子用于心理咨询对话。

| 场所 | 最新位置与处理 | 不能混用的功能 |
| --- | --- | --- |
| 许愿树 | 左上原平台，低枝挂耐候木签，树旁有带小顶的取签盒，石座与挂签通路 | 中央大树不再承担许愿树功能；私人纸和聊天不能自动成为留言 |
| 观景台 | 右上既有平台，保留石坐具与北向、侧向视野，承接日出云海和远眺落日 | 不在此平台放对话小屋，不以房顶阻挡观景 |
| 中央大树 | 原位置保留，作为普通景观和路径节点 | 不再加挂留言，避免形成两棵功能重复的许愿树 |
| 对话小屋 | 主院最右侧、原侧室以外新增一间小屋，短廊与石径接入，门侧向、窗看庭园 | 不替换原独处侧室，不伪装成真人诊室 |
| 原独处侧室 | 位置和私密用途保留 | 仍是无回应的临时表达，不能自动进入 AI |

### 留言与对话的设计边界

许愿树公开路径为写签、主动选择「公开挂出」、审核、通过后可见；作者可撤回，他人可举报。匿名是当前呈现建议，具体方式待实施前核对。美术稿不填真实用户内容，木签只表达功能形态。

新小屋承接用户需要的心理咨询式 AI 对话，主动开启后复用 Invelle 现有聊天与授权体系。可只坐、可文字、可按权限开启语音，也可随时回到园境；不因进入小屋自动追问或开麦。

公开留言、私人许愿草稿、临时侧室文字、抄写笔迹与聊天记录分别处理。公开留言与聊天的授权不能互相推导。
