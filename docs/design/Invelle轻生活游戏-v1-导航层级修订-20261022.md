# Invelle 轻生活游戏 v1：导航层级修订

日期：2026-10-22。依据：Mark 本次明确修正“先从俯视图，进到每个空间，然后再到第一视角”。本说明优先于 2026-10-21 文档中直接从 N00 第一视角进入的描述。

进入顺序固定为：全园俯视图（WORLD_OVERVIEW）→ 所选空间全景（SPACE_OVERVIEW）→ 显式点击“进入第一视角”（FIRST_PERSON）。返回按相反顺序逐级退出，全园返回才离开园境。全园地图与空间全景不触发第一视角物件操作，也不拖动镜头环顾。

全园使用既有模型导出的 CAM_LAYOUT_TOP 正交相机；空间全景复用空间定位点并以应用层概览相机观察；第一视角使用对应已导出的相机世界姿态。保留 N00–N13 作为空间和视点标识，额外使用 level 表达导航层级，不新编一套地点编号，不修改 Blender 主文件。

当前样板开放廊下、鱼塘、许愿树三处；其余空间按依赖继续开发，不把地图轮廓视为功能完成。地图标记和原生“选择空间”列表均先进入空间全景。不同空间之间的选择也先回到目标空间全景，不能跳过中间层直接进入第一视角。

原生 GardenShell 持有 nodeId、level、操作模式与待完成跳转。场景到达回执必须同时匹配请求、空间和层级。资源失败或取消保留上一个稳定空间与层级；后台恢复及内容返回保留当前层级。全园只加载公共纹理、地形和全园概览包；进入空间再按需准备相应区域包。

验收路径：首次全园 → 鱼塘全景 → 鱼塘第一视角 → 返回鱼塘全景 → 返回全园；廊下、许愿树同样执行。横竖屏切换、后台恢复、取消与失败不得跳级。模拟器和 Mac 浏览器分别记录证据；真机触摸与舒适度另列未验证。
