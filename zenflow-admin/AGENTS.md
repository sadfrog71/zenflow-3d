# Invelle 管理后台补充规则

继承[根规则](../AGENTS.md)，已在上下文中无需重读。后台任务按需查[管理后台说明](../docs/项目协作指南.md#admin)和当前专题修订。

- 复用 Vue / Element Plus / Pinia；页面在 `src/views/zenflow/`，请求在 `src/api/zenflow/client.ts`，身份在 `src/stores/identity.ts`，导航在 `src/App.vue`。经产品网关调用，不直连供应商或旧环境。
- 资料和回答示例保持明确入口；区分固定 / 检索参考、索引状态、草稿、准备、试聊和发布，上传成功不等于已生效。模型连通测试、激活和陪伴发布分别处理，密钥不回显或持久存入浏览器。
- 试聊只用手工上下文和获准资料，用户管理不提供私人正文；社区只审核明确提交版本。SSE 取消 / 失败 / 迟到结果和并发编辑冲突如实处理，不静默覆盖。
- 从本目录执行 `npm run build`（类型检查与构建），没有单独 `npm test` 脚本；交互变化补浏览器验证。真实激活、发布、审核、停用和删除按授权执行，不当作只读测试。文档修改只作静态检查。
