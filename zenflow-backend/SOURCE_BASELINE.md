# 此间服务端来源

本工程在 2026-10-04 从只读参考副本 `references/matrix/matrix-backend` 的 `3154567a87acce67e6ac7f69d8f832c4a7cc2bcc` 派生。原代码及其来源记录保留，Invelle 业务在本工程独立开发。上层仓库已有私有远端，目前仍未提交或推送。

## 实际复用

- 认证、账号、OAuth 与 RBAC；产品消费者和管理员使用不同身份边界。
- 原 AssistantRunEngine、会话/消息/运行与事件存储及流式模型契约；Invelle 执行适配接入原引擎，不另造聊天运行体系。
- 原 managed Skill 包解析、审核、发布、版本绑定和执行服务。
- 原 CapsuleService 的私人正文、修订和来源数据；产品扩展只保存授权和状态，不另存第二份私人正文。
- 原 ai_model、ai_dataset、ai_document、ai_slice 等存储结构。公共资料维护已接入，冻结快照已本地验证；向量检索与公共引用仍在实施。

## 产品新增与环境边界

Invelle 的海外账号适配、私人数据授权、陪伴配置、模型管理入口、移动端与管理页面属于产品新增或适配。只装配产品需要的能力，旧企业接口由白名单拦截。

已移除复制来的旧部署脚本、示例账号和旧环境配置。Invelle 的服务、数据库、Redis、域名和密钥配置在 ubuntu-sg 独立测试部署，使用本产品账号和数据。实际部署和验收状态以 `../docs/Invelle核心功能开发状态-20261006.md` 为准；早期 P0 文档的待配置说明属于历史阶段，不能当成当前状态。
